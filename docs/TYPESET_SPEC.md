# 組版仕様（TYPESET_SPEC）

`scripts/typeset.py` が実装する配置規則の **唯一の正**。数値はすべてフォント units
（1000 upm・Y 上向き）、または設計グリッドのセル数で記す。実装と本書が食い違ったら本書を直すか
実装を直すかを決めてから作業する。

> 著作権者: RadianN_kswg / ラジアン（柏木主税） / ライセンス: CC BY 4.0
> 状態: v0.1（2026-09-08）。本家 v4.0-beta（`basis/` 参照コミット）に対して実測した値。

## 1. 入力の契約

| 使う | 出所 |
| --- | --- |
| advance / lsb | `hmtx` |
| GPOS カーニング | `basis/scripts/generate_roman.py::load_kern_pairs`（本家実装を共用） |

## 2. 設計グリッド

PenchantManufacture の字面は **28×40 セル**のグリッドに量子化して設計されている。

| 実測 | units | セル |
| --- | --- | --- |
| cap height（`X` `1` `Σ`） | 660 | **40** |
| x-height（`x` `m`） | 462 | 28 |
| 最大字幅（`m` `w` のインク幅） | 462 | **28** |
| ステム幅（hyphen の縦幅、`\|` の横幅） | 99 | **6** |
| アセンダ（`√` `²` の上端） | 793 | 48 |
| ディセンダ（`g` `₂` の下端） | −198 | −12 |
| 上付き字 `²`（y 範囲） | 463–793 | 28–48（高さ 20） |
| 下付き字 `₂`（y 範囲） | −198–132 | −12–8（高さ 20） |
| hyphen インク y | 231–330 | 14–20 |

よって **1 セル `U` = 660 / 40 = 16.5 units**。

- `q(v)`: セル単位へ丸め。`q_up(v)`: 切り上げ。
- 数式軸 `axis` = hyphen インク中心 = **17 セル**。分数バー等の線幅 `rule` = **6 セル**。
- サイドベアリングはセルに乗っていない（例 `m` lsb 1.64 セル）。advance も非整数セル。
  したがって横方向は **インク左端**をセル境界に乗せる（§3）。

### 出力 px

`--cell N` で **1 セル = N px**、変換は外側 `<g>` の `matrix(s,0,0,−s,tx,ty)` 1 つ（`s = N / U`）。
セルに乗った座標はすべて整数 px に落ちる。字形自体の ±0.5 unit 丸め（660.44 等）による
サブピクセル AA は残る（フォント側の値であり組版では触らない）。

## 3. ボックスモデル

`Box(w, a, d, lsb, items)`: 幅・ベースラインからの上下の広がり・インク左端・子要素。
子は `(dx, dy, s, Box)` / `("path", d)` / `("rect", x, y, w, h)` / `("clip", y_lo, y_hi, Box)`。

`Box.put(dx, dy, box, s=1)` は配置時に量子化する:

- `dx ← q(dx + s·lsb) − s·lsb`（インク左端をセル境界へ。advance との差は ≤ 0.5 セル）
- `dy ← q(dy)`（字面は元々セルに乗っているので原点を丸める）
- `s` は上付き／下付き代替（§5）でのみ 0.5、他は常に 1

### 横並び（hbox）

- 単独グリフ同士は GPOS カーニングを加算（`generate_roman.py` と同じ経路）。
- `BINARY`（`+ - = × ÷ ± ∓ ≤ ≥ ≠ ≈ ≡ ∈ ∉ ⊂ ⊃ ⊆ ⊇ ∧ ∨ ∩ ∪ ∝ →`）に含まれる字は、行頭・行末でなければ
  前後に `OP_GAP = 11 セル`。
- `\,` = 10 セル、`\ ` = space の advance。

### 縦積み（vstack / 複数行）

行 i の baseline = 前行 baseline − (前行 d + `LINE_GAP` 12 セル + 当行 a)。横は中央揃え。
1 行目の baseline が親の baseline。

## 4. 構造ごとの配置

### 4.1 分数 `\frac{N}{D}`

```
width = q_up(max(N.w, D.w)) + 2·rule
bar   = rect(0, q(axis − rule/2), width, rule)          # y 14–20 セル（hyphen と同じ帯）
N     : baseline = axis + rule/2 + FRAC_GAP + N.d        # FRAC_GAP = 6 セル
D     : baseline = axis − rule/2 − FRAC_GAP − D.a
```

分子・分母は幅中央揃え。入れ子は再帰。

### 4.2 可変高括弧 `\left X … \right Y`（`( ) [ ] { } |`）と根号の縦画

**等倍伸縮はしない。** 字を水平に分割し、間に断面幅の矩形（延長片）を差し込む（`Font.delim`）。

1. `Font.cuts(g)`: y を 4 units 刻みで走査し、`stem_span(g, y)`（水平線とアウトラインの交点の
   x 範囲）が一定な区間＝**垂直ステム区間**を列挙。最長区間と同じ断面を持つ区間がもう 1 つあれば
   長い順に **2 箇所**、無ければ最長の **1 箇所**を切断位置とする（区間中点）。

   | 字 | 断面（セル） | 切断 y（units） | 備考 |
   | --- | --- | --- | --- |
   | `( )` `[ ]` | 8 | 330 | 中央 1 箇所 |
   | `{ }` | 8 | 132 / 412 | 突起（y 170–270）を避ける |
   | `\|` | 8 | 124 / 536 | 中央の切れ目（y 300–360）を保存 |
   | `√` | 6 | 432 | 縦画（x 195–294、y 170–694） |

2. 延長量 `ext = q_up(必要高さ) − q(字高)`（セル整数）。2 箇所の場合、中央意匠が伸長後の全高の
   中心に来るよう下側の延長量を `q(y0 + H/2 − (c1+c2)/2)` で配分（元字形では `{` の突起が下寄り
   1/3 にあるため均等配分だと沈む）。
3. 断片は SVG `clipPath` で `[y0−1, c1]`, `[c1, c2]`, `[c2, y1+1]` にクリップし、上の断片ほど
   延長量ぶん持ち上げる。延長片は `rect(x_l, c_i + off_i − 3, x_r − x_l, gap_i + 6)`（±3 units は
   AA の継ぎ目隠し）。
4. インク中心を内容の中心 `(inner.a − inner.d)/2` に合わせる。必要高さ ≤ 字高なら元字をそのまま置く。

### 4.3 根号 `\sqrt{X}`

```
top   = X.a + 2·rule
rad   = delim("√", top + X.d, (top − X.d)/2)             # 縦画を延長
bar_x = stem_span("√", 中央)[1] = 294                    # 縦画右端から上線を始め、頂点の面取りを覆う
x     = q_up(x1 + rule)                                  # X の左端（x1 = √ のインク右端 360）
bar   = rect(bar_x, rad.a − rule, q_up(x + X.w + rule) − bar_x, rule)
```

上線の太さ＝根号の横画＝ステム幅（6 セル）、上端＝根号のインク上端。斜め画は伸ばさない。

### 4.4 大型演算子の上下引数 `\limits{S}{lo}{hi}`

本家 `FUTURE_PLAN` §3-3 の規則: **上引数は下付き字、下引数は上付き字**で組む（演算子に近い側へ
寄る）。実グリフが無い字は §5 の代替。

```
hi : baseline = S.a + LIMIT_GAP + hi.d      # LIMIT_GAP = 4 セル
lo : baseline = −S.d − LIMIT_GAP − lo.a
```

3 要素は幅中央揃え。`∑` 等が本家 OTF に入れば `\sum` がそのまま S になる。

### 4.5 行列 `\matrix{… & … \\ …}`

列幅 `q_up(列内最大幅)`、列間 `COL_GAP` 20 セル、行間 `ROW_GAP` 10 セル。各セルは列内中央揃え。
行列全体をインク中心が数式軸（17 セル）に来るよう配置。括弧は `\left … \right` で付ける。

## 5. 上付き・下付き

| 条件 | 処理 |
| --- | --- |
| 引数の全字が `SUPER` / `SUB` 表にあり、フォントに実グリフがある | 実グリフに**置換**（無縮小・同一 baseline） |
| それ以外 | 引数全体を **50% 縮小**し、上付きは baseline **+28 セル**（実上付き字の下端 = x-height）、下付きは **−12 セル**（実下付き字の下端）に置く |

`SUPER`: `0–9 + − = ( ) n i` → `⁰–⁹ ⁺ ⁻ ⁼ ⁽ ⁾ ⁿ ⁱ`、`SUB`: `0–9 + − = ( ) n` → `₀–₉ ₊ ₋ ₌ ₍ ₎ ₙ`。
50% 縮小は「収録済み上付き字が本体の 50%（高さ 20 セル）で作られている」実測に合わせた値で、
本家に実グリフが増えたら表へ 1 行足すだけで置換に切り替わる。縮小するとステムは 3 セル相当になる
（本家の上付き字は 6 セルのまま設計されている）。

---

## 6. 出力

- SVG: `<title>` に式、`<desc>` にクレジット。`fill` は `--color`、背景は `--bg` の `<rect>`。
- PNG: cairosvg でラスタライズ後、Pillow で tEXt `Author` / `Copyright` を付与。
- 画像サイズ = `(q_up(w) + 2·MARGIN) × (q_up(h) + 2·MARGIN)` セル × `--cell` px（`MARGIN` = 8 セル）。

---

## 7. エラー

- フォント未収録の字 → `ValueError("フォント未収録の字: '∑' (U+2211)")`。代替は `FALLBACK`
  （現在 `−` U+2212 → hyphen のみ）。
- 未対応コマンド・括弧不整合・`^`/`_` の位置不正 → `ValueError`。
- 延長片の断面が取れない（切断位置にインクが無い） → `ValueError`（`cuts` が垂直ステム区間を選ぶため
  通常は起きない）。
