## 0. 目的と「TeX 対応」の定義

**目標は 2 層ある。両方をこの 1 本で追う。**

| 層 | 内容 | 判定 |
| --- | --- | --- |
| **L1 記法互換** | LaTeX（amsmath 相当）の数式ソースを**そのまま貼って通る**こと | 既存の TeX 文書からコピペした式が `ValueError` にならない |
| **L2 組版能力** | TeX で書ける数式**表現**を、可能な限り本パイプラインで出せること | 環境・スタイル・装飾・アトム間空きが TeX と同じ見た目の理屈で決まる |

L1 だけでは「通るが TeX と違う見た目」になり、L2 だけでは「良い組版だが既存資産が使えない」。
**L1 を先に広げ、L2 を後から深める**（フェーズ順の根拠）。

対象は **数式モード**のみ。段落組版・相互参照・数式番号は射程外（§6）。

### 現状の位置づけ

v0.1 は「TeX **風**の最小サブセット」で、TeX ソースをそのまま食べられない。実測した差分:

- LaTeX 数式でよく使う命令 **115 種**を実測したところ、`COMMANDS` に登録済みは **27 種**。
- 未登録の 88 種のうち **20 種はフォントに字がある**（＝実装コストほぼゼロで増やせる・X1）。
- 残る **68 種はフォント未収録**（本家の作字待ち・§5）。登録済み 27 種のうち
  `\sum` `\prod` `\int` `\cdots` の 4 種も未収録／代替のまま（合計 **71 種**が未収録）。
- 環境（`\begin{pmatrix}` 等）・数式スタイル（`\displaystyle`）・関数名（`\sin`）・
  アクセント（`\hat`）・罫線装飾（`\overline`）は**構文ごと非対応**。
- `\limits{Σ}{lo}{hi}` `\matrix{…}` は**本家独自記法**で TeX には無い（§3 X4・X5 で置換）。

## 2. 各フェーズの詳細

### X0 — 入力の受け口を TeX に合わせる

| 項目 | 現状 | 対応 | 変更箇所 |
| --- | --- | --- | --- |
| `$…$` `\(…\)` `\[…\]` | `$` は未収録字として `ValueError` | 前後の数式デリミタを剥がし、`\[…\]` は display スタイル（X3）の既定にする | `parse()` の前処理 |
| `%` コメント | `%` が字として組まれる | 行末まで捨てる。`\%` はリテラル | `tokenize()` |
| `~`（改行しない空き） | 未対応 | space の advance と同じ扱い | `atom()` |
| `\\[2pt]` の省略可能引数 | `[` が字として残る | 読み捨てる（行間の微調整は非目標・§6） | `atom()` |
| 二重添字 `x^2^3` | 後勝ちで**黙って**上書き | TeX と同じくエラー（`Double superscript`） | `Parser.seq()` |
| エラーメッセージ | 「未対応のコマンド: \foo」 | **入力中の位置**と前後 10 字を添える | `Parser` に `self.i` を持たせる |
| 未収録字 | `ValueError` | メッセージに「本家の作字待ち」か「TeX でも未定義」かの別を出す | `Font.name()` |

**受け入れ**: `tests/corpus/*.tex` の式が例外なく `parse()` を通る（§7）。

### X2 — アトム種別とスペーシング

現状は `BINARY` 集合に入る字の**前後に一律 `OP_GAP` = 11 セル**。TeX は原子を 7 クラスに分け、
**隣り合うクラスの組で空きを決める**。§3 に設計値、ここに実装方針を書く。

- `BINARY: set[str]` を **`ATOM: dict[str, str]`**（字 → `"ord"|"op"|"bin"|"rel"|"open"|"close"|"punct"`）へ置換。
  命令から作った `Box` にもクラスを持たせる（`Box.cls`）。
- `hbox()` は隣接ペアのクラスから空きを引く（§3 の表）。行頭・行末では空きを入れない。
- **Bin → Ord の降格規則**（TeX と同じ）: 直前が無い／`bin` `rel` `open` `punct` のいずれかなら、
  その `bin` は `ord` として扱う。これで `-x`（単項マイナス）と `a - x`（二項）が別の空きになる。
- `\left…\right` は `open` / `close`、`,` `;` は `punct`、大型演算子は `op`。
- **上付き・下付きの中（script スタイル）では空きを入れない**（TeX の規則）。X3 と同時に入れる。

**受け入れ**: `a-b` と `-b`、`a,b` と `a+b` の幅が設計値どおりに違うことをテストで固定。

### X3 — 数式スタイル（D / T / S / SS）

TeX は `\displaystyle`(D) `\textstyle`(T) `\scriptstyle`(S) `\scriptscriptstyle`(SS) の 4 段を持ち、
**分数・大型演算子・添字の見え方がスタイルで変わる**。現状は「常に T 相当＋添字は一律 50% 縮小」。

- `layout(font, node, style)` にスタイルを引き回す（既定 `T`。`\[…\]` と `--display` で `D`）。
- 添字に入ると `D,T → S`、`S,SS → SS`。分子・分母は 1 段下がる（`D → T`、それ以外は 1 段下）。
- **縮小率は TeX（70%/50%）ではなく本フォントの実グリフに合わせる**（§4・重要な意図的差分）。
- D と T の差（実装対象）:

| 項目 | D | T |
| --- | --- | --- |
| `\frac` の分子・分母 | T スタイル・`FRAC_GAP` 大きめ | S スタイル・`FRAC_GAP` 小さめ |
| 大型演算子の添字 | **上下**（`\limits` 相当） | **右肩・右下**（`\nolimits` 相当） |
| `\lim` の添字 | 下に置く | 右下 |

**受け入れ**: `\sum_{i=1}^{n}` が D で上下・T で右肩に付く、`\frac` の分子高さが D と T で違う。

### X4 — `\sum_{i=1}^{n}` 記法と `\limits` の後置化

現行の `\limits{Σ}{lo}{hi}` は **TeX に存在しない 3 引数形**。TeX は「大型演算子に `_` `^` を付ける」だけ。

- `ATOM` の `op` クラスに `_` `^` が付いたら、スタイルが D なら上下配置（現行 `layout("limits")` の経路）、
  T なら通常の右肩・右下（現行 `layout("script")` の経路）へ振り分ける。
- **後置修飾子** `\limits` `\nolimits` `\displaylimits` を実装し、直前の `op` の既定を上書きする。
- 旧記法 `\limits{S}{lo}{hi}` は **1 リリースだけ受けて deprecation 警告**、次で撤去（§8-2 で作者判断）。
- `\int` は TeX 既定が `\nolimits`（D でも右肩）。`\sum \prod` は `\limits`。**演算子ごとに既定を持つ**。

**受け入れ**: `\sum_{i=1}^{n} a_i` が README のプレビューと同じ配置で組める（`Σ` 直書きでも同じ）。

### X5 — 環境 `\begin{…} \end{…}`

TeX 数式の多くは環境で書かれる。現行の `\matrix{a & b \\ c & d}` は**本家独自形**。

| 環境 | 内容 | 実装 |
| --- | --- | --- |
| `matrix` | 括弧なし | 現行 `layout("matrix")` をそのまま |
| `pmatrix` `bmatrix` `Bmatrix` `vmatrix` `Vmatrix` | `( )` `[ ]` `{ }` `\| \|` `‖ ‖` 付き | `matrix` を `delim` で包む。**`‖`（U+2016）は未収録**（§5） |
| `cases` | 左 `{` ＋ 2 列**左揃え** | `vstack(align="left")`（[HANDOFF_PLAN.md] T7 と同じ実装） |
| `array` | 列指定 `{lcr\|}` ＋ `\hline` | 列揃えを列ごとに持つ。`\hline` `\|` は `rect`（分数バーと同じ線幅） |
| `align` `aligned` `alignat` | `&` で縦揃え | [HANDOFF_PLAN.md] T3。`&` 直前までの幅を集めて列幅を決める |
| `gather` `gathered` | 中央揃え複数行 | 現行の `\\` と同じ |
| `split` `multline` | 継続行 | `align` の派生。優先度低 |
| `smallmatrix` | S スタイルの行列 | X3 の後 |
| `substack` | 添字の多段 | X3 の後 |

- **共通実装**: `\begin{名前}` `\end{名前}` を `\left…\right` と同じくブロックとして読む
  パーサ層を 1 つ足し、`名前 → (左デリミタ, 右デリミタ, 揃え, 行間)` の表で分岐する。
- 旧 `\matrix{…}` は `\begin{matrix}` の別名として残す（互換維持のコストが小さいため）。
- `&` は環境の外では TeX と同じくエラー（現行は `("amp",)` として素通り）。

**受け入れ**: `\begin{pmatrix}1&0\\0&1\end{pmatrix}` が現行 `\left(\matrix{…}\right)` と同じ Box を作る。

### X6 — 関数名・演算子名

`\sin` `\log` `\lim` などは TeX では**立体の複数字＋ `op` クラス**。本フォントは 1 書体しか無いので、
**ラテン小文字をそのまま並べて `op` クラスを与えるだけ**で実装できる（作字不要）。

- 対象（TeX/amsmath の既定 32 種）: `\arccos \arcsin \arctan \arg \cos \cosh \cot \coth \csc \deg
  \det \dim \exp \gcd \hom \inf \ker \lg \lim \liminf \limsup \ln \log \max \min \Pr \sec \sin
  \sinh \sup \tan \tanh`。
- `\lim \max \min \sup \inf \det \gcd \Pr \limsup \liminf` は **D スタイルで添字を下に置く**（X4 の表を共用）。
- `\operatorname{名前}` / `\operatorname*{名前}` を実装し、上の 32 種はその糖衣にする。
- `\bmod`（Bin クラス・両側 medium）と `\pmod{n}`（`(mod n)` を quad 空きで置く）を追加。
- 名前の内部では**アトム間の空きを入れない**（`\sin` の `s i n` に Bin 空きが入らないこと）。

**受け入れ**: `\sin x` の `x` の前に thin 空きが入り、`sin` の字間はカーニングのみ。

### X7 — 罫線装飾・分数の変種

**フォントに無い図形は「分数バーと同じステム幅の矩形」だけで描く**という既存の契約
（[AGENTS.md]「メトリクスの読み方」）の範囲で実装できるものを集めた。**作字不要**。

| 命令 | 実装 | 備考 |
| --- | --- | --- |
| `\overline{X}` | `X.a + FRAC_GAP` に `rule` の矩形 | 幅は `q_up(X.w)` |
| `\underline{X}` | `−X.d − FRAC_GAP` に同じ | |
| `\boxed{X}` | 4 辺に `rule` の矩形。内側余白は 1 ステム分 | |
| `\sqrt[n]{X}` | 現行 `\sqrt` の根号の左肩に `n` を S スタイルで置く | 根号の斜め画の上端に合わせる。配置式は [TYPESET_SPEC.md] §4.3 へ追記 |
| `\dfrac` `\tfrac` | `\frac` にスタイルを固定して渡す | X3 の上に乗る |
| `\binom{n}{k}` `\dbinom` `\tbinom` | バー無しの縦積み ＋ `\left( \right)` | `\atop` の糖衣として実装 |
| `\atop` `\over` `\choose` | TeX プリミティブ（中置） | 中置なので `seq()` で左辺を巻き取る。優先度低 |
| `\stackrel{a}{=}` `\overset` `\underset` | 上下に S スタイルで積む。クラスは下側（`\overset` は下）に従う | `\limits` の配置式を流用 |
| `\frac` の入れ子 | 実装済み | X3 でスタイルが 1 段下がるようになる |

> `\overbrace` `\underbrace` `\widehat` `\widetilde` は**横方向に伸びる図形**が要る。
> 現行の `Font.delim` は**垂直ステム区間を探して縦に伸ばす**専用で、そのままでは使えない。
> 「`cuts()` の水平版（垂直断面を走査して横に伸ばす）」を書くか、本家へ作字を起票するかは §8-4。

### X8 — アクセント

**本フォントに結合分音記号（U+0300–U+0314）は 1 つも無い**（実測）。一方、
**先合成のアクセント付きラテンは本家 P7a で 72 字収録済み**（`â ê î ô û ā ē ī ō ū á à ä ã å ç ñ` 等を確認）。

したがって TeX のアクセントは **`SUPER`/`SUB` と同じ「置換表」方式**で実装できる:

| 命令 | 表 | 例 | 引数が 1 字でない／表に無いとき |
| --- | --- | --- | --- |
| `\hat{a}` | circumflex 表 | `â` | エラー（`\widehat` は §8-4） |
| `\bar{a}` | macron 表 | `ā` | **`\overline` へフォールバック**（X7・見た目が近い） |
| `\tilde{a}` | tilde 表 | `ã` | エラー |
| `\acute{a}` `\grave{a}` `\ddot{a}` | acute / grave / diaeresis 表 | `á à ä` | エラー |
| `\dot{a}` `\check{a}` `\breve{a}` `\vec{a}` | ▲ 未収録（`ȧ ǎ ă a⃗`） | — | §5 で起票 |

- 表は `basis/docs/glyph_map.txt` から**自動生成する**（Unicode 正規化 NFD で「基底＋結合記号」に
  分解し、結合記号ごとに逆引きを作る）。手書きの表を置かない＝本家に字が増えれば自動で増える。
- `\mathring{a}` → `å`、`\c{c}` → `ç` も同じ機構で入る。

**受け入れ**: `\hat{a}` が `â` の実グリフ 1 字と同一の Box になる（縮小・重ね描きをしない）。

## 3. アトム種別とスペーシング（X2 の設計値）

### 3.1 単位の換算

TeX は `mu`（math unit、18 mu = 1 em）で空きを指定する。本フォントは 1 em = 1000 units、
1 セル = 16.5 units なので **1 em = 60.61 セル**。TeX の 3 種の空きをセルへ丸めると:

| TeX | mu | em | units | **セル（採用値）** | 現行 |
| --- | --- | --- | --- | --- | --- |
| thin space | 3mu | 1/6 | 166.7 | **10** | `THIN` = 10（一致） |
| medium space | 4mu | 2/9 | 222.2 | **13** | — |
| thick space | 5mu | 5/18 | 277.8 | **17** | — |

> 現行の `OP_GAP` = 11 セルは二項演算子と関係子の**両方**に使われている。TeX に合わせると
> 二項は 13、関係は 17 で、**関係子まわりが今より 6 セル広がる**。これは意図した変更であり、
> `\times` を多用する算数の問題画像では見た目が変わる。導入時に `docs/previews/` を再生成すること。

### 3.2 クラス表（TeX 18 章）

行 = 左の原子、列 = 右の原子。`0` = 空きなし、`1` = thin(10)、`2` = medium(13)、`3` = thick(17)。
**丸括弧付きの値は D／T スタイルのみ**。S／SS スタイル（添字の中）では 0 にする。

| ↓左＼右→ | Ord | Op | Bin | Rel | Open | Close | Punct | Inner |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **Ord** | 0 | 1 | (2) | (3) | 0 | 0 | 0 | (1) |
| **Op** | 1 | 1 | — | (3) | 0 | 0 | 0 | (1) |
| **Bin** | (2) | (2) | — | — | (2) | — | — | (2) |
| **Rel** | (3) | (3) | — | 0 | (3) | 0 | 0 | (3) |
| **Open** | 0 | 0 | — | 0 | 0 | 0 | 0 | 0 |
| **Close** | 0 | 1 | (2) | (3) | 0 | 0 | 0 | (1) |
| **Punct** | (1) | (1) | — | (1) | (1) | (1) | (1) | (1) |
| **Inner** | (1) | 1 | (2) | (3) | (1) | 0 | (1) | (1) |

`—` は TeX では起こらない組み合わせ（Bin の降格規則で潰れる）。

### 3.3 クラス割り当て

| クラス | 対象 |
| --- | --- |
| **Ord** | 英数字・ギリシャ・`∞ ∂ ∇ ∀ ∃ ∅ ¬ ℏ ℓ ∴ ∵ …` |
| **Op** | 大型演算子（C2 15 字・▲）、`\sin` 等の関数名（X6）、`\operatorname` |
| **Bin** | `+ − × ÷ ± ∓ · ∪ ∩ ∧ ∨ † ‡`（▲ `∘ ⊕ ⊗ ∖ ∗`） |
| **Rel** | `= < > ≤ ≥ ≠ ≈ ≅ ≡ ∝ ∈ ∉ ∋ ⊂ ⊃ ⊆ ⊇ ⊢ ⊨`（▲ 矢印 15 字・`⊥ ∥ ∼ ≃ ≪ ≫`） |
| **Open** | `( [ {`（▲ `⟨ ⌈ ⌊`） |
| **Close** | `) ] }`（▲ `⟩ ⌉ ⌋`）、`!`（階乗）は **Ord** |
| **Punct** | `, ;`（`.` は小数点なので **Ord**） |
| **Inner** | `\left…\right` の結果、`\frac`、環境全体 |

**Bin → Ord の降格**: 直前の原子が無い、または `Bin` `Rel` `Open` `Punct` のとき、その `Bin` は
`Ord` として扱う（`−x` の単項マイナス、`(−1)` など）。

## 4. 数式スタイル（X3 の設計値）

### 4.1 縮小率は TeX と変える（意図的な差分）

TeX の既定は script = 70%、scriptscript = 50%。**本パイプラインは採らない。**

理由: 本家は上付き実グリフ（`⁰–⁹ ⁿ ⁱ`）を **本体の 50%・高さ 20 セル**で作字しており、
ベースラインも x-height（28 セル）／ディセンダ（−12 セル）に固定して設計している
（[TYPESET_SPEC.md] §5）。70% にすると**実グリフと縮小代替が並んだとき大きさが揃わない**。
**実グリフとの整合を TeX の数値より優先する**（[HANDOFF_PLAN.md] §3 の既存決定を踏襲）。

| スタイル | 倍率 | 根拠 |
| --- | --- | --- |
| D / T | 100% | 本体 |
| S | **50%** | 実上付き字の実測（高さ 20 セル = 本体の 50%） |
| SS | **§8-1 で作者判断**（50% 据え置き／25%） | 25% はステム 1.5 セル相当。`--cell 3` で 4.5px となり潰れる |

> 現行実装は `x^{y^z}` のように 2 段重なると **0.5 × 0.5 = 25%** になる（`_small` が
> 部分木ごと 0.5 倍するため）。これは「SS = 25%」を**無自覚に選んでいる**状態なので、
> X3 でスタイルを明示的に持たせるときに決着させる。

### 4.2 スタイル遷移（TeX と同じ）

| 位置 | D | T | S | SS |
| --- | --- | --- | --- | --- |
| 上付き・下付き | S | S | SS | SS |
| `\frac` の分子・分母 | T | S | SS | SS |
| `\sqrt` `\overline` の中身 | 同じ | 同じ | 同じ | 同じ |
| `\limits` の上下引数 | S | S | SS | SS |

### 4.3 スタイルで変わる配置

| 項目 | D | T | 実装 |
| --- | --- | --- | --- |
| `\frac` の `FRAC_GAP` | 6 セル（現行） | **3 セル** | スタイル別の定数表 |
| 大型演算子の添字 | 上下（`LIMIT_GAP` 4 セル） | 右肩・右下 | X4 |
| `\lim` 等の添字 | 下 | 右下 | X6 |
| アトム間の空き | §3.2 の括弧付き値を適用 | 同じ | S・SS では 0 |

**CLI**: `--display` / `--text`（既定 `--text`）を足す。`\[…\]` は `--display` 相当（X0）。

## 6. 非目標（やらないと決めたこと）

| 項目 | 理由 |
| --- | --- |
| `\mathit` `\mathbf` などの**書体切り替え** | 本フォントは 1 ウェイト・1 スタイル。**斜体は本家 §0-3 で凍結**されており、将来も入らない |
| `\mathbb` `\mathcal` `\mathfrak` `\mathscr` | 同上（黒板太字・筆記体・フラクトゥールの作字予定なし）。`\mathrm` のみ**恒等命令**として受ける |
| 数式番号 `\tag` `\label` `\ref` `\eqref` | 1 枚の画像に組む用途に番号の管理主体が無い。番号が要るなら呼び出し側が文字列で入れる |
| `\newcommand` `\def` などマクロ定義 | 入力は Bot の 1 行式が主。マクロ展開器を持つ価値が薄い。必要なら呼び出し側で展開して渡す |
| 段落組版・行分割・ハイフネーション | 本リポジトリの責務は**数式の 1 枚組版**（[AGENTS.md] 責務分界） |
| `\color` `\textcolor` | 出力全体の色は `--color`。式中の部分着色は要望が出てから |
| 和文（`\text{日本語}`） | **PenchantManufacture-CJK の責務**（[HANDOFF_PLAN.md] T2）。本家には作字しない |
| TeX への出力（`.tex` 生成・LaTeX パッケージ配布） | 本書の対象は**入力の互換と組版能力**。出力側の TeX 連携は要望が出た時点で別途 |

## 7. 受け入れ基準とテスト

### 7.1 互換コーパス

`tests/corpus/` に **実在の LaTeX 式**をテキストで置き、フェーズごとに「通る率」を測る。

```
tests/corpus/
├── basic.tex        # 四則・添字・分数・根号（X0 時点で 100%）
├── operators.tex    # 大型演算子・関数名（X4・X6）
├── environments.tex # matrix 族・cases・align（X5）
├── decoration.tex   # overline・binom・accent（X7・X8）
└── blocked.tex      # ▲ 未収録グリフが要る式（落ちてよい。理由付きで落ちること）
```

- テストは「例外なく `layout()` が通る」ことと、`blocked.tex` は**未収録グリフ由来の
  `ValueError` のみ**で落ちること（構文エラーで落ちたら互換バグ）を確認する。
- **互換率をテスト出力に出す**（`operators.tex: 24/31 (77%)`）。フェーズの進捗指標にする。

### 7.2 回帰

| 対象 | 方法 |
| --- | --- |
| 既存 6 テスト | `python tests/test_typeset.py` が通り続けること |
| アトム空き（X2） | `a-b` / `-b` / `a,b` / `a+b` / `a=b` の幅を**セル数で**固定 |
| スタイル（X3） | 同じ式を D と T で組み、分数の高さ・添字位置が設計値どおり違う |
| アクセント（X8） | `\hat{a}` の Box が `â` 単字の Box と一致（`scale(` を含まない） |
| プレビュー | 空き・スタイルを変えた**同じコミット**で `python scripts/build_previews.py` を回す |

### 7.3 グリッド不変条件

X2〜X9 のどの段階でも [TYPESET_SPEC.md] §2 の契約を壊さないこと:

- 位置・間隔は**すべてセルの整数倍**（`test_grid_quantized` を新構造にも広げる）。
- **ベースラインを組版側で動かさない**。
- 拡大縮小は**スタイル縮小と上下付き代替のみ**。括弧・根号は分割＋延長片のまま。
